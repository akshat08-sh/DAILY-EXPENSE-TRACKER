# Daily Expense Tracker

This is a simple Python project for keeping track of daily expenses. It allows the user to add, view, search and delete expenses and also shows basic expense summaries.

## Features

* Add expenses
* View all expenses
* Delete expenses
* Search by category or description
* Calculate total and average expenses
* Check expenses for a particular day
* Set monthly budget
* View today's and complete summary

## Technologies Used

* Python
* File Handling
* Lists and Dictionaries
* Functions
* Exception Handling
* `datetime`

## Data Storage

The project uses text files instead of a database.

* `data.txt` stores expense details
* `budget.txt` stores the monthly budget

Example:

```text
28-09-2026|Food|150.0|Lunch
28-09-2026|Travel|50.0|Bus
```

## How to Run

1. Install Python.
2. Save the code as `main.py`.
3. Open the terminal in the project folder.
4. Run:

```bash
python main.py
```
